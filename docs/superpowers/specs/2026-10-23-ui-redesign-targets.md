# 界面改版目标（从 DESIGN.md 移出）

日期：2026-10-23

以下内容原在 `DESIGN.md`，属于一轮改版的计划和目标布局，不是长期规范。保留供追溯；是否已实现以源码为准，现行规则见 `DESIGN.md`。

## 已知问题（改版依据）

多页表面颜色接近、标题与容器反复嵌套；热榜中部利用不足；写作素材与结果同时占大面积；账号详情偏重按钮、缺内容预览；手机首屏被页头与筛选占满。

## 页面目标布局

只用已有真实数据，不新增采集、模型或统计能力。

| 页面 | 布局 |
| --- | --- |
| 视频热榜 | 概览页头 → 紧凑筛选 → 榜单；宽屏可切精选 / 列表视图，保留筛选 |
| 热点雷达 | 单行工具栏 + 简短总览 + 卡片 / 分类总览 + 按需详情 |
| 对话写作 | 无独立标题栏；左侧设定与素材约 30–35%，右侧稿件约 65–70% |
| 账号库 | 账号列表 240–280px + 视频区 + 可收起详情 320–380px |
| 评论生成 | 输入与设置侧栏 + 结果主区，历史按需展开 |
| 工具台 | 视频、发布文案、PDF 模块同时展示，高度随内容 |
| 毛利维护 / 监控 | 真实指标摘要 + 操作栏 + 主数据表，详情按需 |
| 手机首页 | 后台状态 → 任务进度 → 常用操作 |

## 改版顺序

先统一导航、页头、颜色、字体、控件和面板（改共享 token）；再以视频热榜和写作台为样板；最后迁移其他页面，保留各自任务结构。同一份数据、同一窗口对比改版前后截图。
